## 二、主指标表（AD 通道，输入 125 kHz，20 s，144 帧）

| 指标 | 数值 | 条件 / 说明 |
|---|---|---|
| 峰值频率 | 125.000 kHz | peak_idx=32，32×3.90625 kHz |
| 峰值幅度 | 11333（11301~11353） | 中位（最小~最大） |
| 帧率 | 7.2 fps | 144 帧 / 20 s |
| 丢帧 | 2 帧 | 缺失序号 482、483 |
| 校验错 | 0 | 全部包校验和通过 |
| 噪声底 floor_mag | 1 ~ 2 | 头部字段 |
| SNR | 75 ~ 81 dB（中位 81） | snr_db |
| SFDR | 44 ~ 53 dBc（中位 51） | sfdr_dbc |
| THD | -100 ~ -90 dBc（中位 -99） | thd_dbc |
| SINAD | 58 ~ 74 dB（中位 69） | sinad_db |
| ENOB | 9.3 ~ 12.0 bit（中位 11.1） | enob_x10/10 |
| ped 近端杂散 | -75 ~ -46 dBc（中位 -54） | 主峰 ±4~±24 bin |
| skirt 裙边 | -75 ~ -61 dBc（中位 -69） | ±24~±64 bin |
| far 远端杂散 | -81 ~ -69 dBc | 其余全部 bin |
